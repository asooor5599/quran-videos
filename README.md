# quran-videos

إنشاء فيديوهات القرآن الكريم ورفعها على يوتيوب تلقائياً (تشغّلها مسارات n8n).

| الملف | الوظيفة |
|---|---|
| `.github/workflows/quran-long.yml` | سورة كاملة: خلفية طبيعة متحركة + الآيات بالرسم العثماني مع الترجمة الإنجليزية متزامنة مع التلاوة، ثم الرفع مباشرة على يوتيوب (جلسة رفع من n8n) |
| `.github/workflows/quran-video.yml` | سورة كاملة بالتصميم الثابت (صورة السورة + الصوت) للقراء اللي ما لهم توقيت آيات |
| `.github/workflows/quran-short.yml` | شورت عمودي ~20 ثانية: آيات كاملة لقارئ عشوائي + خلفية طبيعة + النص والترجمة |
| `.github/scripts/*.py` | الرسم والتركيب (Chrome + ffmpeg) |

المصادر: الصوت من mp3quran.net و everyayah.com، النص من alquran.cloud (عثماني + Saheeh International)، الخلفيات من Pixabay.
